# Projects

Use this page for details that are too long for a portfolio card. A useful project write-up usually covers:

1. The problem and constraints
2. Your role and decisions
3. The architecture or approach
4. Measurable results
5. What you learned

## Project template

```markdown
## Project name

**Context:** What problem did this solve?

**My role:** What did you personally own?

**Approach:** How did the system work?

**Result:** What improved, preferably with numbers?
```
